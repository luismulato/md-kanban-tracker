md-kanban-tracker

VS Code meets Kanban, with WIP tracking built in — no external scripts, no watchers.

Get the .vsix on GitHub Original project (kanban.md)

md-kanban-tracker is a fork of kanban.md by Withney Guilherme, licensed MIT — the license is kept as-is, and all credit for the original architecture and design goes to its author. This fork is not affiliated with or endorsed by the original project.

Features

Single WIP task

Drag a second task into WIP and the previous one goes back to the top of To Do, automatically.

Daily Done archiving

The first task to enter WIP each day archives everything in Done into Done Done — no manual cleanup.

WIP-synced timer

Moving a task into WIP starts its timer; moving it out stops it and logs the time. No watcher process required.

Editable title

Click a task's title to rename it in place. Enter saves, Escape reverts — without closing the modal.

Discoverable due date

Click anywhere in the due-date row to open the native calendar picker, not just the small icon.

Pure Markdown

Your data stays in .md files. No lock-in, no sync, no cloud.

Quick Start

Create a file ending in .kanban.md and open it with the Kanban view:

# My Board

## To Do
### Task one
### Task two

## In Progress
### Working on this

## Done
### Completed task

Why md-kanban-tracker?

  • No context switching — manage tasks without leaving your editor
  • Version control friendly — it's just Markdown, commit and diff as usual
  • Works offline — no account, no internet required
  • No external scripts — WIP limits and time tracking run inside the extension itself
